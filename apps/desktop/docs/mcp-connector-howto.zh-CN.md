# 开物 MCP（连接器）对照操作手册

适用对象：市场、运营等非技术同事  
目标：按本页 **真实例子** 从头点到尾，配好连接器并在对话里真正用起来

> 界面按钮、字段名称以开物当前版本为准。若某按钮找不到，先核对左侧是否在 **专家 · 技能 · 连接器** 能力页，并切到 **连接器** 标签。

---

## 真实例子：用 LibTV 生成一张「春季上新」主视觉

本例使用产品支持的真实远程服务 **LibTV**（LiblibAI，用于 AI 生图 / 生视频）。  
你只需要准备 **一把访问令牌**；其它字段下面都写好了，照抄即可。

### 开始前只做一件事

向你们的产品对接人 / 管理员要一把 **LibTV 访问令牌（Access Key）**。

- 有人会写成 `LIBTV_ACCESS_KEY`
- 长得像一串英文数字密钥
- **不要发到群里、不要贴进公开文档、不要截进清晰截图**

拿到令牌后，把下面清单勾完再往下做：

- [ ] 已打开 **开物 Desktop**，能登录
- [ ] 已能新建对话
- [ ] 访问令牌已拿到（先放在备忘录里，待会儿粘贴）

---

### 第 1 步：打开「MCP 服务管理」

任选一条路径（会到同一页）：

**从对话进（推荐）**

1. 新建或打开任意对话  
2. 点输入框左侧的 **连接器** 按钮  
3. 点底部 **「↗ 管理连接器」**

**从侧栏进**

1. 左侧点 **「专家 · 技能 · 连接器」**  
2. 顶部点 **「连接器」**

看到页面标题 **「MCP 服务管理」** 即成功。

---

### 第 2 步：先看列表里有没有「LibTV」

打开管理页后看卡片列表：

| 你看到的情况 | 怎么做 |
|--------------|--------|
| 已有卡片 **LibTV**（常见，产品会预置） | 点开卡片 → 点 **「编辑」** → 跳到下面「第 3 步·编辑」 |
| 列表里没有 LibTV | 点 **「＋ 添加 MCP」** → 跳到下面「第 3 步·新建」 |

未填令牌时，状态经常是 **「连接异常」**，先别慌，补令牌后再刷新。

---

### 第 3 步：把表格里的内容原样填进弹窗

弹窗标题是 **「编辑 MCP」** 或 **「添加 MCP」**，字段一样。  
**传输方式务必选「Streamable HTTP」**（默认可能是「stdio 本地进程」，要改掉）。

| 界面字段 | 本例请填（可直接复制） |
|----------|------------------------|
| 显示名称 | `LibTV` |
| 服务标识 | `libtv` |
| 说明 | `生图、生视频与画布创作` |
| 传输方式 | **Streamable HTTP**（下拉选择，不要选 stdio） |
| MCP URL | `https://mcp.liblib.tv/mcp` |
| 访问令牌 | 粘贴你拿到的 Access Key（整串粘进去即可；一般不用自己加 `Bearer`） |

填写示意（对照弹窗从上到下）：

```text
显示名称：LibTV
服务标识：libtv
说明：生图、生视频与画布创作
传输方式：Streamable HTTP
MCP URL：https://mcp.liblib.tv/mcp
访问令牌：（此处粘贴你的密钥，界面会显示成圆点）
```

然后：

1. 点蓝色 **「保存并连接」**  
2. 回到列表，点 **「刷新状态」**  
3. 看 **LibTV** 卡片：状态变成 **「已连接」**，并显示「N 个工具」

**本步完成勾选**

- [ ] LibTV = **已连接**
- [ ] 卡片上能看到工具数量（至少 1 个）

> 若提示服务标识已被占用：说明列表里已有 `libtv`，请不要再「添加」，改为找到现有卡片 **编辑**，只补访问令牌即可。  
> 若令牌框提示「已安全保存；留空表示保持不变」：密钥没换就留空，只点保存。

---

### 第 4 步：在对话里点「使用」（不做这一步，AI 调不到）

1. **新建一条对话**（新对话默认不会自动带上连接器）  
2. 点输入框左侧 **连接器**  
3. 找到 **LibTV**，右侧点 **「使用」**（应变为 **「已选」**）  
4. 确认输入框旁边出现 **LibTV** 名称  

**本步完成勾选**

- [ ] 输入框旁能看到 LibTV

---

### 第 5 步：复制下面这句话发出去（验收）

把整段复制到输入框，直接发送（可按活动改文案）：

```text
请使用已选的 LibTV，生成一张电商「春季上新」主视觉海报：
- 主题：春季上新，清新自然
- 主色：浅绿与米白
- 画面：简约产品展示，留出右下角放价格字的空白
- 风格：商业摄影，干净明亮
- 不要出现：真实人脸、杂乱文字、水印
请先出图，再简短说明构图建议。
```

**成功长什么样**

- AI 会调用 LibTV 相关能力推进生图  
- 或给出可理解的进度 / 结果说明  

若立刻报错「未连接 / 无工具」，回到第 3 步看状态是否仍是 **已连接**，并确认本对话已点过 **「使用」**。

**本步完成勾选**

- [ ] 已发送上面的验收话术
- [ ] 对话有正常推进，或对接人能根据报错继续排查

---

### 本例一句话口令

**填好 LibTV（URL + 令牌）→ 刷到「已连接」→ 新对话点「使用」→ 粘贴验收话术发送。**

## 附录 A：以后换别的在线 MCP，怎么套用

还是同一套操作，只换对接人给你的四样东西：

| 字段 | 换成对方给的 |
|------|----------------|
| 显示名称 | 对方起的中文名，或你自己起 |
| 服务标识 | 对方约定的英文 id（不要和已有重复） |
| MCP URL | 对方的 `https://……/mcp` |
| 访问令牌 | 对方的密钥（没有就留空） |

传输方式仍然选 **Streamable HTTP**，保存并连接 → 对话里点「使用」→ 用自然语言下任务。

---

## 附录 B：状态与按钮对照

| 管理页状态 | 你要做什么 |
|------------|------------|
| 已连接 | 去对话里点「使用」 |
| 正在连接 | 等一会儿，再点「刷新状态」 |
| 连接异常 | 多半是令牌或 URL 不对；编辑后重存，仍失败把详情红字发给对接人 |
| 已停用 | 打开卡片开关，再刷新 |

| 对话里按钮 | 含义 |
|------------|------|
| 使用 | 把该服务加入**本次**对话 |
| 已选 | 已加入；再点一次即取消 |
| 连接异常 | 先回管理页修好 |

| 日常维护 | 操作 |
|----------|------|
| 暂时不用 | 卡片右上角开关关掉 |
| 换令牌 | 编辑 → 粘贴新令牌 → 保存并连接 |
| 删除 | 详情里「删除此 MCP」→ 确认 |

## 附录 C：本地进程（stdio）— 市场同事不要单独做

只有研发明确要求时才选 **stdio 本地进程**，并按他们给的「启动命令 / 参数」填写。  
没有研发在场：**一律用本页 LibTV 例子的 Streamable HTTP。**
