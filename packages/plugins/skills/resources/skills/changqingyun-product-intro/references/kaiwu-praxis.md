# 开物 Praxis

依据：产品彩页、基于 DeepSeek Harness 的能力说明、轻量化与企业级部署组合介绍、与 WorkBuddy 的对比。冲突时，对比稿里的「对外不要说成已经做好」优先于彩页中的方向性表述。

## 定位

开物 Praxis 是加在 DeepSeek Harness（DSH）上的企业 AI 工作台，随客户自己的设备交付。DSH 负责把一次任务跑起来；开物负责岗位、资料、成果和本机/企业管理。

一句话：把岗位上的事，做成能交出去的文件；把人、模型与记录放进企业的控制台。

和 WorkBuddy 的选择口径：

- 客户要的是服务器进机房之后业务能验收，对话、文件和凭据留在自己的环境：讲开物。按员工做完的工作验收，不按聊天窗口验收。
- 客户要的是马上给员工一个办公助手，并且已经在用企业微信、腾讯会议、腾讯文档：讲 WorkBuddy。
- 两边都能谈私有化。材料写 WorkBuddy 私有化官方从 300 席起，并带腾讯生态。开物的差异是跟着常青云硬件一起交付，不把先买一套公有云当作前提。不比较价格，不把对方未公开能力说成事实。

## 可讲能力

个人端在员工电脑：召唤数字员工、引用资料库、在对话右侧修改并导出演示文稿、文档、表格、网页和 PDF。写入外部系统、外发或删除，由使用人当次确认。

企业控制台在企业内网：部门与成员、角色、公司模型、会话查阅、操作记录。彩页数字：部门树最多 10 层；角色为所有者、管理员、普通成员；普通成员不进后台。模型密钥在服务器，成员使用内部凭证，不接触上游密钥。会话查阅是只读，不能改对话或代执行。

DSH 继续负责：任务执行、模型接入、技能发现与调用、MCP、会话、附件、工具执行前确认、桌面和网页里的对话界面。开物不另写一套智能体运行时。

开物补上的、材料写明可以讲的：

- 数字员工：创建、配备技能、发布版本后能力固定；旧任务不自动换成后来的配置。召唤前检查技能是否齐备。
- 技能：安装、启用、停用、卸载；停用后仍在。内置演示文稿、文档、表格、网页等办公技能。
- 协作空间：任务、计划和资料放在一起，不是本机文件夹本身。
- 资料库：按选定版本引用。能力说明中的上限是单文件 50MB、本机资料总量 5GB。
- 办公成果：工作副本，不覆盖原文件。演示文稿可导入单位模板并导出 PPTX；文档可导出 DOCX；表格可编辑单元格和普通公式；PDF 可分页更新；网页可设计和预览。页眉页脚、复杂版式、带高级对象的表格导出，材料写明并不完整，导出后要人工看。
- 连接器：凭据和当次对话分开；向外部系统写入需本人确认。
- 图片理解：配置视觉模型并打开视觉增强后识别截图或扫描件，可单独关闭。

彩页列出的预置岗位顾问是容器运维、需求分析、文档评审、工作复盘。现场以当前安装包里实际能召唤的数字员工为准，不要把彩页人数说成「永远只有四位」，也不要把材料没写的能力说成已验收。

## 两种部署（同一套工作台）

| | 轻量化：开物 + NVIDIA Jetson AGX Thor | 企业级：开物 + GPU 服务器 |
| --- | --- | --- |
| 适合 | 一个部门、网点、现场或关键岗位先跑通 | 多部门或全组织，信息部门统一管 |
| 硬件 | Jetson T5000；材料写最高 2070 TFLOPS FP4（稀疏）；128GB 统一内存；标配 1TB；功耗约 40–130W | 按并发人数和模型规模配置，不绑定单一机型 |
| 模型与数据 | 本地模型和开物同机，资料留在现场设备 | 多模型并存，控制台统一管成员、模型和审计，数据留在客户机房 |

路径：先用一体机验证岗位，再把数字员工、技能和资料迁到机房 GPU 服务器。客户只想一个岗位先用 AI、数据留在现场：推 Thor。客户要多人分权、多模型、必须私有化：推 GPU 服务器。

开物不自建训练平台。模型推理在盒子或客户 GPU 服务器上完成。不要把开物说成 ANI 的模型训练产品。

## 对外不要说成已经做好

对比稿明确列出，当前对外不能当成已验收能力：

- 数字员工团已经在分工执行。材料写界面目前不提供团。
- 管理端已经能按部门下发、停用数字员工，并完整收回工作事实。员工端和管理端闭环在目标里，多人治理还没有完整验收。
- 任意 Word、PPT、表格版式都和原文件一致。
- 用开物替代 WorkBuddy 的腾讯会议、腾讯文档、企业微信原生读写。

行业技能（例如常青云装机、巡检）是否随安装包预装，以当前安装包为准。对比稿写过「需单独安装，未安装时数字员工会显示技能未安装」。若现场安装包已内置，就说当前版本已带上，不要同时说两套互相矛盾的状态。
