# 排版工具

纯PDF原票优先使用[脚本与批量填报](automation.md)中的`compose_invoice_pdf.py`，支持多页原票和独立加印；本页旧工具保留给确实需要DOCX或图片票的场景，不为两票拼版重复编写临时代码。

这是可选的单页发票排版助手，不定义最终交付目录。最终按SKILL.md输出每批“费用报销”“差旅报销”两个打印文件夹，其余存“原始文档”。已有用户确认的可打印PDF优先复用；不为使用此脚本强制重做Word或拆成多个交付分组。

示例打印规则（请先确认本单位要求）：付款截图仅电子上传，不制作打印Word或PDF。发票每面可排两张，允许双面打印；专票及通行发票每张还须额外单独加印一张，不与其他票拼版。脚本不自动识别这些票种或生成加印件，需从核实的原票另行准备并明确标注用途；加印不增加原票数与报销金额。纸质粘贴位置为左上角。生成分页不等于已设置或完成实体双面打印，交付时说明打印方式。

脚本会输出分组DOCX和“图片布局预览”PDF。可在原始文档下生成，逐页确认完整、清晰、金额与页序正确后，将适用的PDF按本批费用/差旅顺序合并或复制为最终“发票打印清单.pdf”“出差发票打印清单.pdf”。交付PDF时无须等待Word转换；不要未经检查把预览改名便称合格。索引、清单和其他辅助文件留在原始文档。

多页或长票按本批安排完整保留，可将原PDF所有页连续附入最终清单或独立打印，不拆首页绕过限制。付款截图保留电子原图供对应费用项上传，既有历史截图Word不重做；OA原件直接复用，不用此脚本重建。费用日期缺失时不在台账伪造日期，记录按开票日排序；无法适配脚本就选择其他简单排版方式。

费用网约车发票纳入费用发票清单；费用行程单只用于电子提交，不进入最终纸质目录。此脚本仅排原票，不生成审批后的申请单或付款截图。

运行环境：使用 `load_workspace_dependencies` 查到的 Python，需 python-docx、pypdfium2、Pillow、reportlab。脚本不联网、不读邮箱、不执行附件。

```text
python build_print_pack.py 清单.json --output 新输出目录
```

清单由总控核实资料后生成，示例结构（值仅为格式说明，不是实际票据）：

```json
{
  "reimbursement_month": "2026-09",
  "trips": {
    "TRIP001": {
      "destination": "昆明",
      "period": "2026-08-30至2026-09-02",
      "application": "出差申请.pdf"
    }
  },
  "invoices": [
    {
      "invoice_id": "DEMO001",
      "file": "酒店票.pdf",
      "category": "外地差旅",
      "subtype": "酒店",
      "trip_id": "TRIP001",
      "expense_date": "2026-09-01",
      "issue_date": "2026-09-02",
      "amount": "300.00",
      "currency": "CNY",
      "verified": true
    }
  ]
}
```

`file` 与 `application` 可为绝对路径或相对清单所在目录。允许的分类：外地差旅（酒店/外地打车）、成都本地用车及招待费（本地用车/招待费）。实际报销月份必须由用户指定；文件日期可跨月。

工具拒绝：重复发票ID、重复原文件哈希、缺少必要日期、未核对票据、负数或零金额、非CNY、多页PDF、多帧图片、出差申请缺失或不明确分类。先修正清单或将例外移到待核对，不改原发票以绕过检查。跨月已报销去重、发票内容一致性、审批状态由调用者核对，工具不能通过 `verified: true` 证明其真实。

输出每组docx（两票一页），配套PDF图片布局预览，print-index.csv 与 trip-applications.csv。出差关联说明独立CSV，不插入两票排版页；需申请随票打印时另行排入独立页。PDF布局预览没有Word表格标题文字，不代表WPS实际页数；请对最终Word打印预览验收。

图片/PDF页面以200dpi渲染并保持比例；不自动裁边或修补票面。纵长票据被缩放后可能过小，必须视觉检查；必要时作为排版例外处理。
